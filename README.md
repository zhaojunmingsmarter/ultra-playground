# 奥特曼 · 招式乐园

儿童动画风的 iPad 触控小游戏。四位奥特曼、三种招式、原创循环音乐和同步合成音效。无需账号、依赖、广告或内购。

## 怎么玩

- 点“开始玩”后，音乐启动。选择迪迦、赛罗、泰罗或初代，再点变身、格斗或光线。
- 每个角色有独立的准备、格斗与光线姿势，动画配合蓄力、移动、粒子及光束。
- 点右下角叫怪兽出来一起练招。没有血条、失败惩罚、计时压力或解锁门槛。
- 长按右上角“家长”两秒，分别开关背景音乐、招式音效与播报，调整音量，开启“跟我做”倒数模式。键盘可按住回车或空格两秒打开。
- 切后台或锁屏后暂停；回来点“继续玩”恢复，避免突然出声。
- PWA：Safari 分享 → 添加到主屏幕，保留“作为网页 App 打开”（若出现），再点添加。主屏幕图标会以独立窗口打开。首次联网加载并完成离线保存后，游戏图片、音乐与音效可离线使用；系统中文播报取决于设备语音包。家长设置中可查看离线保存状态。
- 页面禁用捏合及双击缩放，保留单指滚动；系统级辅助功能缩放由 iPad 设置控制。
- 设置只保存在当前设备，存储不可用时仍可玩。

## 本地运行与验证

```sh
npm run build
python3 -m http.server 8080 --directory _site
# 打开 http://localhost:8080
npm run check
npm test
node scripts/build.mjs
```

无需 npm install。原生 ES Modules、Canvas 2D、Web Audio 和语音合成。
中文播报使用设备语音能力，未安装中文声音的设备可能表现不同；音乐和音效由本地 Web Audio 合成。

## 发布

GitHub Settings → Pages 已选择 GitHub Actions。推送 main 会运行检查、测试、构建与部署。
构建只发布 scripts/build.mjs 中列出的文件，所有资源使用相对路径，支持项目子路径。

## 美术和音频

最终需求为儿童动画风；早期特摄照片研究不进入游戏发布包。最终素材见 assets/ART.md。
角色为 AI 辅助制作的同人动画演绎，并非官方素材或原作动画帧。角色名称及设定属于各自权利人。
音乐是项目内编写的短循环旋律；音效为合成音效，不冒充影视原声。

## 验证边界

自动测试覆盖动作不排队、连续点击、角色切换取消、倒数时序、暂停恢复、两秒家长门槛以及音频关闭/清理。
浏览器检查覆盖 iPad 尺寸横竖屏、角色和招式、图片加载及控制台错误。真实 iPad Safari 的扬声器音量和系统中文语音需在设备上最终试听。
