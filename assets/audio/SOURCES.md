# Character battle sounds

Short character sound clips from community soundboards, stored locally so gameplay has no third-party audio requests. These are source-labelled character clips, not newly synthesized actor voices. No system speech narration is used.

- Tiga: “Ultraman Tiga (Sound Effects) V2”, mmumon: https://tuna.voicemod.net/sound/d9583a46-30cb-4c6c-85c2-6fae0c15c858
- Zero: “Ultraman Zero - 4 - デフ!”, Heroes' VS (PSP) voice board: https://www.101soundboards.com/sounds/53852965-ultraman-zero-4-dehu
- Taro: “taro sound 2”, Pepper1: https://tuna.voicemod.net/sound/7b176beb-7dfc-4d84-a9a1-4009081cb0e5
- Original Ultraman: “ultraman rise”, Pepper1: https://tuna.voicemod.net/sound/a621d004-d951-4540-8b13-2d306febc179

Processing: trim initial silence, loudness normalization to -18 LUFS / -2 dB true peak, mono 32 kHz / 64 kbps MP3. Original character attribution belongs to the respective rights holders; community labels are not official authentication. Punches, whooshes, beam layers, shield chimes, monster calls and music are locally synthesized by this game.
